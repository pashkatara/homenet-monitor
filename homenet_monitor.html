📡 Интеграция с роутером

Синхронизация имён устройств, Wi-Fi клиентов и статуса сети

Как настроить доступ в KeeneticOS:
  1. Откройте веб-интерфейс вашего Keenetic (обычно http://192.168.1.1 или http://192.168.1.1).
  2. Перейдите в меню: «Управление» → «Пользователи и доступ».
  3. Нажмите кнопку «Добавить пользователя» (например, логин: monitor).
  4. В блоке прав доступа включите: «Доступ к командной строке и веб-интерфейсу».
  5. Сохраните пользователя в Keenetic и укажите его логин и пароль в полях выше.
  6. Либо используйте учётную запись главного администратора (admin).
Как настроить доступ в OpenWrt:
  1. В OpenWrt веб-сервер uhttpd и интерфейс LuCI включены по умолчанию.
  2. Для синхронизации имён DHCP и Wi-Fi устройств через JSON-RPC подключитесь к роутеру по SSH и выполните:
    opkg update && opkg install rpcd-mod-luci
  3. Введите IP адрес роутера (обычно 192.168.1.1), логин root и ваш пароль от панели LuCI.
  4. Нажмите «Проверить подключение» для проверки авторизации через ubus API.

Используется для проверки пинга до шлюза и построения схемы топологии сети.

Универсальный автономный режим (любые роутеры):
  • Работает с роутерами любых производителей (Mikrotik, TP-Link, Asus, Xiaomi, Tenda, D-Link и др.) без необходимости вводить пароль.
  • Монитор сканирует устройства через системную ARP-таблицу Linux ядра и ICMP-пинг.
  • Производители оборудования (Apple, Samsung, Xiaomi, Tuya) определяются автоматически по базе MAC-адресов.
  • Названия устройствам вы можете дать в один клик прямо в панели карточек сети.
